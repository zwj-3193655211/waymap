# Waymap · 路线规划地图

> 单文件路线规划地图，给旅游出行、三下乡、研学旅行用。

在地图上拖放站点，画连线把它们串起来，标记每个站点已完成 / 待办，最后**把整段行程导出成一个独立的 HTML 文件**——任何人都能用浏览器直接打开，不需要安装、不需要服务器。

## 文件

| 文件 | 说明 |
|---|---|
| `路图.html` | 主程序（精简版），用任何现代浏览器打开即可 |
| `路图 - 可编辑日志版.html` | **增强版**：在 `路图.html` 基础上增加了「站点日志」功能（详见下文） |
| `favicon.svg` | 站点图标 |
| `key获取方法.txt` | 如何申请免费的高德 Web 服务 API Key |

## 功能

- 在高德地图上添加 / 编辑站点
- 节点列表支持上下排序，站点编号随列表顺序自动变化
- 连线画多段路线
- 标记每个站点为待办 / 已完成，自带进度统计
- 待办事项支持「高 / 中 / 低」优先级（红 / 黄 / 灰 三色区分）
- 地点搜索，支持宣纸（高德）/ 卫星两种底图切换
- 一键导出 → 单 HTML 文件（团队分享的杀手锏，导出时包含全部行程数据）
- **站点日志（仅增强版）**：双击任意节点打开该站点的图文日志，支持 Markdown 富文本、插图、章节分段

## 可编辑日志版 · 站点日志功能

打开 `路图 - 可编辑日志版.html`，双击左侧节点列表里的某个站点，即可进入该站点的「日志」面板：

- **所见即所得编辑**：加粗、斜体、下划线、列表、引用等格式化工具；下划线写作 `++文字++`。
- **章节分段**：以一个 `#` 一级标题作为一条日志的分隔（`# 日期 · 标题`），下方为正文；`##` / `###` 仅作章节内的子标题，不会拆成独立条目。
- **预览单章节**：右侧预览只渲染当前正在编辑的那一条日志，方便聚焦。
- **三态布局**：底部滑块在「仅编辑 / 双屏 / 仅预览」三种视图间切换，并自动记忆上次选择。
- **窗口化编辑**：日志面板可像窗口一样拖拽标题栏移动；标题栏右侧有「最小化 / 最大化 / 关闭」按钮，最大化时填满浏览器视口，最小化时收为右下角小条，按 `Esc` 直接关闭窗口。
- **本地文件存储**：首次使用连接一个「日志」文件夹（Chrome / Edge 桌面版），日志会以 `.md` 文件落盘到该文件夹下，图片存到 `日志/img/`；刷新 / 重开页面会自动恢复该连接。若环境不支持（如 `file://` 直接打开、移动端、句柄失效），会自动重新提示选择文件夹，或退化为「导入 / 导出 .md」手动管理。
- **相对路径显示**：面板顶部显示当前日志文件的相对路径（如 `日志/trip_xxx_n4.md`），不再需要「连接文件夹」按钮。

## 快速开始

1. 申请一个免费的高德 Key（见 `key获取方法.txt`）

2. 打开 `路图.html` 或 `路图 - 可编辑日志版.html`，按提示粘贴 Key

3. 开始搜索地标、画路线、规划地点任务

4. （增强版）双击节点写站点日志，连接「日志」文件夹后自动保存为 Markdown

## 项目由来

最初是为**三下乡**社会实践做的行程规划工具，但通用性足够强，任何需要按站点串路线的出行场景都能用——研学、徒步、自驾、调研都可以。
